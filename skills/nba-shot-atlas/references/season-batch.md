# 播放节奏（最新修正）

用户明确纠正：单个赛季约20秒，投篮轨迹按原来的逐球方式；1至10个赛季保持逐球，超过10个赛季才模仿科比整季齐发的快节奏。4.6秒单季版本已被否定，不能作为默认。左栏仍为736px（约38%），右侧默认近景呈现进攻半场或大半场，底层保留完整全场及双端篮架，禁止中线硬切地板，取消360°，改为科比参考式稳定近景和缓慢推近。

默认脚本按实际有出手的season数量选择模式，1季20秒，2至10季初值20+3×(季数−1)秒，后者只是实现初值，可根据出手量和用户要求调整。所有逐球记录保留，同一帧允许相邻多次出手开始，但每条轨迹都要完整绘制，不以“60fps帧数小于出手数”为由删球或擅自延长到65秒。

超过10季才用批量模式：参考片45.53秒/20季，约2.28秒/季。一季的所有轨迹同时起弧、完整形态停留、淡出，短暂停顿后下一季。上一季圈叉和统计累计保留。额外约2秒看最终统计。

在create_project准备真实球员项目后运行：

```sh
python scripts/configure_video.py <project>
python scripts/apply_half_court.py <project>
python scripts/apply_scene_framing.py <project>
python scripts/apply_stable_camera.py <project>
python scripts/render_video.py <project> --output <检查目录> --mode check
python scripts/render_video.py <project> --output <成片目录> --mode video
```

配置只应用一次，需要重新调布局时从新的干净项目创建。以下按季齐发细节仅适用于超过10季或用户明确指定批量模式。按CSV的season结束年份分组，同季起点时间相同；不同季间隔约2.28秒。每季弧线使用原始每次出手的世界坐标，含全部命中和未中；不能随机抽样、随机改坐标或改成每条轨迹逐一播放。左侧按已出现赛季的全部记录累计，五区红白总长仍为命中+未中。多季需要检查首季、中间季切换及末季，不能只跑单季检查就声称多季已完整验证。

运镜统一采用稳定近景、小幅单向位移和轻微推近，不做360°旋转，避免多季快节奏时造成晃动。用户指定20秒逐球时可传 --mode shot_by_shot --duration 20；不直接把批量版成片拉长。用户指定批量时可传 --mode season_batch。
