# 缓存优先与制作提速

优先查用户当前工作区已知缓存，其次默认 `~/Documents/Codex/shot-atlas-cache`；也可由用户指定根目录。使用 `scripts/cache_inventory.py <缓存根目录> [--verify]` 查看/校验。缓存属于用户本机，不放Git公开仓库；发布包只带制作代码、许可字体、预设重绘素材与来源说明。

按联盟/赛季/阶段分开，缓存键必须包含源站身份和几何版本：

```text
cba/2025-26/regular/
  coordinate-batches/*.json       # 一场只属于一个批次，保存原始记录顺序
  cba_league_2026.parquet         # 全联盟坐标，其他球员可直接筛选
  league-games.json               # 完整赛程与球队覆盖；按scheduleId去重
  players/21674/
    shots.csv + data-audit.json   # 时间对齐后的逐球与数据缺口
    games.json + official.json   # 正确赛季范围及精确技术统计
    pbp/*.json                   # 必须标明whole-game或player scope
assets/cba/<球队-场馆-年份>/        # court纹理、队标、来源、纹理边界
assets/cba/players/<playerId>.png  # 官方头像，记录来源和抓取时间
templates/cba-fiba-v1/            # 已验证的渲染代码、字体和球场模型
manifest.json                    # schema/几何版本/数据范围/校验和
```

首次获取即落盘：球员身份别名/赛季目录、全联盟赛程、全联盟坐标、完整比赛PbP、精确技术统计、头像队标、主场参考与重绘纹理、字体、已验证的相机/模型配置。后续制作同赛季另一名球员只需筛选坐标、补未缓存逐场PbP及其身份/素材；同队同年球场直接复用。同一头像/字体/球场不在每个视频重新下载/绘制。不提前批量渲染所有球员、也不抓取当前任务之外所有历史赛季。

本次已保存：CBA2025-26常规赛420场、56,584条坐标、368个球员ID，贺希宁612条已绑定时间的逐球、41场该球员事件、精确613次技术统计及1次无坐标审计，深圳龙华球场纹理、头像、队标、CBA标、渲染基础文件及字体。**当前41场PbP是贺希宁过滤结果，其他球员仍需补全场事件**；缓存命中不代表所有后续任务完全零取数。新获取PbP应缓存全场以扩大复用。该季全联盟缓存是坐标覆盖，不代表无任何源站缺失。

已结束赛季优先复用并检查manifest/校验和，用户要求刷新或源站出现修正再更新；进行中赛季先查最新赛程/技术统计，只补新增或修订比赛。源站记录修订时用该比赛的新原始记录替换该场旧批次，而不是追加重复出手。整个赛季坐标不按x/y去重。缺口与日期同缓存存档。

模板缓存用于复用代码/字体/网格，换人仍新建job和项目目录并换shots、头像、球队素材，重算统计和基准；不能带旧人的数字、球队或时间轴。更改渲染脚本时比较几何版本，避免旧prepared模板遮蔽技能修复。机器绝对路径只出现在本机清单，不写入公开脚本。

缓存仅保存已授权访问的业务数据和素材。不要保存Cookie、Authorization、CSRF、登录口令、原始网络抓包、私人对话或浏览器存储；也不要将这些放入Git或安装ZIP。浏览器模块hash可存发现日期与公开URL，失效后正常重新发现。
